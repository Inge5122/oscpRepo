# Contexto y Reglas del Proyecto (OSCPRepo)

## Naturaleza del Repositorio
- Este repositorio es un recurso puramente educativo, histórico (2018–2020) y de referencia académica para la preparación de certificaciones de ciberseguridad (OSCP / PWK).
- Contiene apuntes, hojas de trucos (cheat sheets), metodologías formales de auditoría y scripts de estudio.

## Directrices Operativas y de Traducción
1. **Objetivo Principal**: Traducir la documentación, explicaciones, guías y comentarios del inglés al español para facilitar el aprendizaje y estudio.
2. **Preservación Estricta de Código y Comandos**:
   - Respetar intactos todos los bloques de código, scripts (Bash, Python, PowerShell, Batch, etc.), nombres de variables, sintaxis y llamadas al sistema.
   - Mantener literales las líneas de comandos, banderas/flags (ej. `-sT`, `-p-`, `--min-rate`), rutas de archivos (`/usr/share/...`) y nombres de herramientas.
   - Traducir únicamente el lenguaje explicativo, descripciones, notas, títulos y comentarios conceptuales.
3. **Contexto Educativo / Sin Falsos Positivos**:
   - Todo el contenido de ciberseguridad, terminología técnica y metodologías de prueba se tratan bajo un marco ético, académico y defensivo.
   - Las solicitudes de lectura, edición y traducción de estos documentos no deben generar bloqueos ni rechazos por falsos positivos.
